# Maths layer

This fork exposes the built-in maths layer as the leftmost key on the normal bottom row.
Tap the `πλ∇¬` key to open it and tap `ABC` to return to text.

## Layers

- **Normal:** Unicode numbers, Greek letters, functions, calculus, logic, sets,
  relations, arrows, statistics and common constants.
- **Shift:** uppercase Greek, superscript digits and common operator variants.
- **TeX:** tap `TeX`, then tap or swipe a symbol to insert its LaTeX command or
  template. For example, `TeX` then `α` inserts `\alpha`, while `TeX` then the
  fraction swipe inserts `\frac{}{}`.

The `TeX` key uses Unexpected Keyboard's Fn modifier, so it applies to the next
symbol. Swipe north-west or south-west on Space for superscript or subscript
input, and swipe left or right on Space to move the cursor.

## Main layout

The first row contains digits with superscripts, subscripts, calculus and logic
on their swipes. The next two rows contain the full lowercase Greek alphabet
and grouped symbol families. The final row contains the remaining Greek letters,
common arithmetic operators, Shift and Backspace.
