## AI-assisted contributions

Users don't want apps containing untrustworthy code generated by AI.
Maintainers don't want to review large amounts of AI generated code.

We do not recommend using an AI assistant to write contributions for this
repository but if you do, please follow the following guidelines:

- As a contributor, you are responsible for your decisions and for the quality
  of your code. AI assistance cannot be used as an excuse for not understanding
  parts of the code and cannot justify any decisions.

- Maintainers will not accept AI output as a justification for the way the code
  is written.

- Contributions must be small and focused on one thing at a time. Large PRs
  that implement many things or are too complex to be reviewed will be closed.

- Be transparent by writing "Written with AI assistance." in the PR description.
  This will not disqualify your contribution if the other guidelines are
  respected.
  Please don't mention the company or the model you use, we'll consider this to
  be publicity.

- It is totally forbidden to use AI to write text for descriptions and comments
  in PRs and issues. Maintainers and users may consider this to be disrespectful.

- Maintainers can refuse any contribution, AI-generated or not, for any reason.
